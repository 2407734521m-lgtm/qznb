# UI 试验参考：校园蓝白轻量改版

状态：仅在 `permission-check-20261024-1155` 测试分支试验，未合并、未部署。

## 设计方向
- 保留现有页面结构、路由、登录流程和业务逻辑，不做大规模重构。
- 将深色玻璃拟态调整为更明亮的校园蓝白：浅蓝渐变背景、白色卡片、蓝色主按钮、低对比度边框与柔和阴影。
- 保留原有照片墙、动态、个人档案、相册、聊天和管理后台组件。
- 保留移动端底部导航；减少动态效果偏好仍然有效。
- 本轮只追加样式覆盖，便于在测试分支中快速回退或继续微调。

## 验收重点
1. 登录页文字和输入框在浅色背景下仍清晰。
2. 动态卡片、个人档案、成员墙和管理员后台没有白字/浅底导致的可读性问题。
3. Android 手机窄屏下导航可横向滚动，表单不会横向溢出。
4. 原有主题自定义、上传照片、聊天、登录与权限逻辑不应因样式变化而改变。
5. 不连接生产数据库、不执行 SQL、不合并或部署，直到完成功能与安全验证。
